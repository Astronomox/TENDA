# Contributing to TENDA

1. Create a branch from `main` (`feat/...`, `fix/...`, `docs/...`).
2. Keep changes small and focused; one idea per pull request.
3. Before opening a PR run `npm run typecheck`, `npm run lint` and `npm run build`.
4. Check the change on a phone-width screen; most TENDA users are on mobile.
5. Use clear commit messages, e.g. `feat(customers): add sort selector`.

Money is always Naira (₦) and dates use Africa/Lagos time; use the helpers in `lib/format.ts`.
